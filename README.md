Designed and deployed a traditional **3-tier application architecture** using AWS services.

### 🏗️ Architecture

```text
                🌐 Users
                   │
                   ▼
            ┌─────────────┐
            │   Route 53  │
            └──────┬──────┘
                   │
                   ▼
        ┌────────────────────┐
        │  Presentation     │
        │    S3 Frontend     │
        └─────────┬──────────┘
                  │
                  ▼
        ┌────────────────────┐
        │   Application      │
        │    EC2 Backend     │
        └─────────┬──────────┘
                  │
                  ▼
        ┌────────────────────┐
        │      Database      │
        │    RDS - Private   │
        └────────────────────┘
```

### 🔧 Technologies

`AWS S3` `EC2` `RDS` `VPC` `IAM` `Security Groups` `Route 53`

### ⚡ Key Work

* Designed a **3-tier architecture on AWS**
* Hosted the frontend using **Amazon S3**
* Deployed backend services on **Amazon EC2**
* Configured **Amazon RDS** in a private subnet
* Created public and private subnets using **Amazon VPC**
* Configured security groups for controlled access
* Used **IAM roles** for secure AWS resource access
* Configured **Route 53** for DNS management
* Connected the application backend with the database
